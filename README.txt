GOOGLE SHEETS DATABASE
The published CSV URL is already configured in script.js. Expected column headers (exact spelling):
ID, ProductName, Category, Description, Price, Quantity, ImageURL, Active

Set Active to exactly: active
Categories can be Plants, Pots, or Garden Essentials.
Use a direct, publicly accessible image URL in ImageURL. Quantity should be a number.
The stock page refreshes every 150 seconds. Each product shows its own quantity; total stock is shown separately.
