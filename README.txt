VILLAGE GARDEN NURSERY WEBSITE

Files: index.html, stock.html, contact.html

All CSS and JavaScript are embedded inside each HTML page. No separate styles.css or script.js is required. Each page has its own responsive design.

INSTALL ON GITHUB PAGES
1. Extract this ZIP.
2. Upload the three HTML files to the root of your GitHub Pages repository.
3. Keep the filenames exactly as shown.
4. Open index.html through your GitHub Pages website.

LIVE STOCK
The stock page reads this published Google Sheets CSV URL:
https://docs.google.com/spreadsheets/d/e/2PACX-1vRJfVQDf5xukjGsfktJjCEvfouVYyNkxT_Kt2H5_SSJ8jTEktzcGvu1gK06qJKw36UCVkO2BwYXMAVU/pub?output=csv

Expected columns: ID, ProductName, Category, Description, Price, Quantity, ImageURL, Active.
Set Active to active, yes, true or 1 for products that should appear.
Stock refreshes every 150 seconds. The sheet must be published to the web as CSV and accessible without signing in.
